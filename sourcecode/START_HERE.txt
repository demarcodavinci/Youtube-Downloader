❓ COMMON QUESTIONS

Q: Do I need Python installed?
A: NO! The executable includes everything. Python is optional.

Q: Does it work without internet?
A: NO, you need internet to download from YouTube.

Q: What if FFmpeg doesn't download?
A: It will be skipped. FFmpeg will auto-download on first run.

Q: Can I download multiple videos?
A: YES! Create a batch file to download multiple URLs.

Q: Is this legal?
A: Download only videos you have permission to use.

Q: What if it's slow?
A: Download speed depends on your internet. This is normal.

Q: Can I use on Mac/Linux?
A: YES! Use the Python script instead of the .exe.

🐛 TROUBLESHOOTING

Issue: "FFmpeg is downloading..."
Solution: This is normal on first run. Wait 2-5 minutes.

Issue: "Requested format is not available"
Solution: Try a different video or quality level.

Issue: Executable won't start
Solution: Run from Command Prompt as Administrator.

Issue: Very slow download
Solution: Check your internet speed. This is normal.

Issue: Out of disk space
Solution: Free up 1-2 GB or download lower quality (360p).

For more help, read: GETTING_STARTED.md or MERGER_README.md
